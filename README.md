A one-line dating bio for an AI: fluent in sarcasm, terrible at small talk,
and incapable of ghosting — it literally lives in the cloud, so it is always
online. The program is pure-stdlib Python and writes that one line,
deterministically, to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
